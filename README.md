## 🎮 1. Концепт и Кор-Геймплей

### 💡 Питч
> *«Безопасность требует привязи. Прогресс требует риска.»*

Вам предстоит управлять автономным сервисным роботом-дроном в закрытом научном комплексе. Главная механика игры построена на контрасте двух фундаментальных состояний:

```
 ┌──────────────────────────────────────┐          [ SPACE ]          ┌──────────────────────────────────────┐
 │       РЕЖИМ «ЗАВИСИМОСТИ»            │  ────────────────────────►  │      РЕЖИМ «НЕЗАВИСИМОСТИ»           │
 ├──────────────────────────────────────┤  ◄────────────────────────  ├──────────────────────────────────────┤
 │ • Бессмертие & Постоянная подзарядка │     [ Вход в розетку /     │ • Полная свобода перемещения         │
 │ • Ограниченный радиус (натяжение)    │       Новая база ]         │ • Рывок (Dash) на импульсе отрыва    │
 │ • Провод цепляется за углы и стены   │                             │ • Проход сквозь узкие решетки        │
 │ • Питание внешних систем кабелем     │                             │ • ⚠️ Батарея тает за 6 СЕКУНД!       │
 └──────────────────────────────────────┘                             └──────────────────────────────────────┘
```

### 🎯 Цель игры
Пройти цепочку изолированных секторов, грамотно рассчитывая траекторию натяжения кабеля, вовремя отсоединяясь в автономный режим, преодолевая препятствия и подключаясь к следующей розетке/генератору до полного разряда аккумулятора.

## 🛠️ 4. Технический стек и архитектура

```
[ Game Loop ]
  ├── PlayerController (WASD, скорость, импульс)
  ├── CableSystem (Verlet / Spring / Raycast-Wrap, натяжение, разрыв)
  ├── EnergyManager (6-секундный таймер, зарядка, визуализация)
  ├── InteractiveObjects (Розетки, Лазеры, Решетки, Двери под питанием)
  └── LevelManager (Мгновенный рестарт, загрузка уровней 1–5, переход сцен)
```

### Приоритеты фичей (Scope Management)

| Уровень приоритета | Фичи | Статус |
| :--- | :--- | :--- |
| 🟢 **Must Have (MVP)** | Движение, кабель с натяжением, отстрел (Space), 6с таймер, рестарт, 3 уровня | *В плане* |
| 🟡 **Should Have** | Механика Dash на натяжении, лазеры/решетки, 5 уровней, SFX, частицы | *В плане* |
| 🔴 **Nice to Have (Если успеваем)** | Запутывание кабеля вокруг столбов, переключатели тока, лидерборд по времени | *Опционально* |

## 🕹️ Управление
- **`W` `A` `S` `D` / Стрелочки** — Перемещение дрона
- **`Space` (Пробел)** — Отстрел кабеля / Переход в режим Независимости (Dash)
- **`R`** — Быстрый рестарт уровня
- **`Esc`** — Пауза / Меню
