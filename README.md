# 🎮 PROJECT KOSYLGAN (35 LVL GAME JAM)

Кооперативная 3D-головоломка на движке **Godot Engine 4.x**.

---

## 🤖 Роботы и управление

* **ATLAS (Силовой робот):**
  * `WASD / Стрелки` — Движение
  * `E` — Поднять / Поставить коробку
  * `Пробел` — Прыжок
* **CIPHER (Робот-взломщик):**
  * `WASD / Стрелки` — Движение
  * `E` — Взлом терминалов и миниигры с проводами
* **Общее управление:**
  * `TAB` — Смена активного робота (с плавным переходом изометрической камеры)
  * `R` — Быстрый перезапуск текущей комнаты
