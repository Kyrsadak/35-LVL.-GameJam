# 🤖 PROJECT: KOSYLGAN — Дизайн-Документ v2

> **Тема GameJam:** «Механика Независимости» (35 LVL)
> **Жанр:** 3D Top-Down кооперативная головоломка (single-player, переключение между 2 роботами)
> **Основа:** `top-down-action-adventure-starter-kit-main` (Godot 4.3+)
> **Рабочее время:** ~15 часов

---

## 🧠 КОНЦЕПЦИЯ

### Лор
Заброшенная кибернетическая станция. Системы повреждены. Два автономных робота — **ATLAS** и **CIPHER** — должны восстановить работу 3 блоков станции, чтобы запустить аварийный сигнал. На всю станцию **одна зарядная станция**, и каждый робот тратит батарею, когда не подключён к ней.

### Как раскрывается тема «Независимость»

| Элемент | Как работает |
|---|---|
| **Зарядка** | Отсоединение от зарядки = акт независимости, но с обратным отсчётом батареи |
| **Уникальные способности** | Каждый робот НЕЗАВИСИМ в своей роли — один не может заменить другого |
| **Ручная замена** | Начиная с Уровня 2, игрок САМИ ведёт робота обратно к зарядке — цена независимости |
| **Поиск подсказки** | ATLAS ищет гайд на карте, пока CIPHER ждёт — каждый действует автономно |

## 🎮 ГЕЙМПЛЕЙ — КАК ЭТО РАБОТАЕТ

### Два робота

#### 🔵 ATLAS (Силовой робот)
- **Толкает/перетаскивает** тяжёлые ящики
- **Поднимает и несёт** Ключевой Модуль (предмет для завершения уровня)
- **Находит и читает** гайды-подсказки (записки/планшеты на полу)
- **НЕ МОЖЕТ:** Взаимодействовать с терминалами

#### 🟠 CIPHER (Хакерский робот)
- **Взаимодействует** с терминалами → перерезание проводов
- **Отключает** лазерные решётки, электронные замки
- **НЕ МОЖЕТ:** Двигать ящики / поднимать Ключевой Модуль / читать гайды

### Механика переключения — ПРОГРЕССИЯ ПО УРОВНЯМ

#### Уровень 1 (Обучение): Автоматический режим
```
Нажал TAB → текущий робот ТЕЛЕПОРТИРУЕТСЯ на зарядку
           → управление переходит ко второму роботу
           → второй снимается с зарядки
```
> Игрок учится базовым механикам без стресса.

#### Уровни 2–3: Ручной режим (хардкор)
```
1. Довести текущего робота обратно к зарядке ПЕШКОМ (батарея тикает!)
2. Поставить его на зарядку (нажать E рядом со станцией)
3. Нажать TAB → переключиться на второго
4. Снять второго с зарядки и вести к цели
```
> Теперь каждое переключение стоит ВРЕМЯ и БАТАРЕЮ. Нужно планировать маршрут!

### Механика зарядки

```
БАТАРЕЯ: 100% ████████████ 0%   ОТКЛЮЧЕНИЕ!

Уровень 1: ~45 сек автономности
Уровень 2: ~35 сек автономности
Уровень 3: ~30 сек автономности

- Робот на зарядке = батарея восстанавливается (~5 сек до 100%)
- Робот вне зарядки = батарея медленно садится
- Батарея на 0% = робот отключается → рестарт секции
```

## 🔧 МИНИ-ИГРА: «ПЕРЕРЕЗАНИЕ ПРОВОДОВ»

### Как это работает (полный цикл):

```
1. CIPHER подходит к терминалу → нажимает E
2. Открывается панель с 4-6 проводами разного цвета
3. На экране надпись: "НУЖНА ТЕХНИЧЕСКАЯ СХЕМА. НАЙДИТЕ ГАЙД."
4. Игрок нажимает TAB → переключается на ATLAS
5. ATLAS бегает по карте и ищет планшет/записку на полу
6. Нашёл → подбирает → на экране появляется подсказка:
   "ПЕРЕРЕЖЬ: КРАСНЫЙ, ЗЕЛЁНЫЙ. НЕ ТРОГАЙ: СИНИЙ, ЖЁЛТЫЙ."
7. Игрок запоминает (или подсказка остаётся в углу HUD)
8. TAB → обратно на CIPHER (вернуть ATLAS на зарядку на ур. 2-3!)
9. CIPHER выбирает правильные провода → лазеры выключаются!
10. Неправильный провод → ⚡ штраф (потеря 20% батареи / рестарт)
```

### Прогрессия сложности мини-игры:
| Уровень | Проводов | Перерезать | Подсказка |
|---------|----------|------------|-----------|
| 1 | 3 провода | 1 правильный | Прямая: "Режь красный" |
| 2 | 5 проводов | 2 правильных | Загадка: "НЕ трогай тёплые цвета" |
| 3 | 6 проводов | 3 правильных | Код: "Порядок: 3-й, 1-й, 5-й сверху" |

## 🗺️ УРОВНИ (3 блока станции)

### Уровень 1 — «ЭНЕРГОБЛОК» (Обучение, ~1.5 мин)
**Режим переключения:** Автоматический (TAB = телепорт на зарядку)

| Шаг | Робот | Действие |
|-----|-------|----------|
| 1 | ATLAS | Подвинуть 1 ящик, освободить проход к терминалу |
| 2 | TAB → CIPHER | Подойти к терминалу, открыть панель проводов |
| 3 | CIPHER | Видит надпись "Нужен гайд" |
| 4 | TAB → ATLAS | Найти планшет-гайд на полу (рядом, легко заметить) |
| 5 | TAB → CIPHER | Перерезать 1 правильный провод → лазер выкл |
| 6 | TAB → ATLAS | Взять Энергомодуль, донести до разъёма |
| 7 | ✅ БЛОК ЗАПУЩЕН | Переход на уровень 2 |

**Препятствия:** 1 ящик, 1 лазерная решётка, 1 терминал (3 провода), 1 гайд.

---

### Уровень 2 — «КОММУНИКАЦИИ» (~2 мин)
**Режим переключения:** Ручной! (нужно САМОМУ вести робота на зарядку)

| Шаг | Робот | Действие |
|-----|-------|----------|
| 1 | ATLAS | Подвинуть 2 ящика (один на нажимную плиту → дверь открывается) |
| 2 | ATLAS | Проход к антенне заблокирован двойным лазером |
| 3 | ATLAS | Найти гайд-планшет для терминала №1 (спрятан за ящиками!) |
| 4 | ⚠️ Вручную! | Довести ATLAS обратно к зарядке, поставить на зарядку |
| 5 | TAB → CIPHER | Бежать к терминалу №1 → перерезать 2 провода → лазер 1 выкл |
| 6 | ⚠️ Батарея! | Довести CIPHER к зарядке |
| 7 | TAB → ATLAS | Найти гайд для терминала №2 |
| 8 | Обратно к зарядке | — |
| 9 | TAB → CIPHER | Терминал №2 → лазер 2 выкл |
| 10 | TAB → ATLAS | Забрать Антенну, донести до цели |
| 11 | ✅ БЛОК ЗАПУЩЕН | — |

**Ключевая механика:** Несколько ходок туда-обратно! Планирование маршрута критично.

---

### Уровень 3 — «ЦЕНТР УПРАВЛЕНИЯ» (~2.5 мин)
**Режим переключения:** Ручной + жёсткий таймер батареи (30 сек!)

| Шаг | Робот | Действие |
|-----|-------|----------|
| 1 | ATLAS | Сложный паззл с 3 ящиками + 2 нажимных плиты |
| 2 | ATLAS | Найти гайд (спрятан в дальней комнате за ящиком) |
| 3 | ⚠️ Зарядка | Вести ATLAS на зарядку (далеко!) |
| 4 | TAB → CIPHER | Терминал: 6 проводов, порядок важен, 3 правильных |
| 5 | ⚠️ 30 сек! | Лазеры вокруг консоли выкл |
| 6 | CIPHER → зарядка | Успеть на зарядку! |
| 7 | TAB → ATLAS | Взять Главный Ключ, донести до консоли |
| 8 | ✅ СИГНАЛ ЗАПУЩЕН | Финальный экран! |
